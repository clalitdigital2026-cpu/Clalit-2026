# חביתת אלסטר

משחק קרבות ביצים בתורות עם ארבע דמויות: רוני, שירי, יאיר ועדי אלסטר לדפדפן (HTML5 Canvas + JavaScript, ללא תלויות וללא שרת).

## הפעלה
פותחים את `index.html` בדפדפן (או מגישים את התיקייה בכל שרת סטטי, למשל `python3 -m http.server`).
עובד בעכבר ובמגע, מותאם למחשב ולמובייל לרוחב.

## איך משחקים
לוחצים על הביצה שברוגטקה, מושכים אחורה (המרחק = עוצמה, הכיוון ההפוך = כיוון הירי, 360°) ומשחררים.
גרירה במקום אחר בזירה (או גלגלת/חצים) גוללת את המצלמה. פגיעה בגוף = 20, בראש = 35. 8 שלבים, רוח משלב 4.

## מבנה הקוד (`js/`)
| קובץ | אחריות |
|---|---|
| `utils.js` | מתמטיקה, RNG דטרמיניסטי, צבעים, Local Storage |
| `audio.js` | מוזיקת צ'יפטיון מקורית ואפקטים – מסונתזים ב-Web Audio |
| `physics.js` | פיזיקת קליע בצעד קבוע + זיהוי התנגשויות רציף (משותף לביצה, לתחזית ול-AI) |
| `weapons.js` | נשקים סודיים: גיטרה, גלובוס, שוקולד ומכחול צבעים |
| `characters.js` | איור וקטורי של רוני, שירי, יאיר ועדי אלסטר, הבעות ומצבי אנימציה |
| `levels.js` | 8 עולמות, יצירת שטח פרוצדורלית, מכשולים ומסכת התנגשות פיקסלית |
| `background.js` | שמיים, שכבות Parallax, עננים |
| `particles.js` | קליפות, חלמונים, קונפטי, טקסט נזק, מזג אוויר |
| `ai.js` | יריב ממוחשב: חיפוש זווית/עוצמה בסימולציה אמיתית + שגיאה שקטנה עם הלמידה |
| `ui.js` | מסכים, HUD, כרטיסי דמויות |
| `game.js` | מכונת מצבים, תורות, קלט, מצלמה ורינדור |
| `main.js` | אתחול ולולאה ראשית |

## לוח תוצאות משותף (Firebase)
עד שממלאים את `js/config.js`, לוח התוצאות נשמר רק במכשיר. כדי שיהיה משותף לכולם:
1. יוצרים פרויקט חינמי ב-console.firebase.google.com, ומוסיפים בו **Firestore Database**.
2. בלשונית **Rules** של Firestore מדביקים את התוכן של `firestore.rules` ומפרסמים.
3. ב-Project settings ← Your apps ← מוסיפים Web app, ומעתיקים את `apiKey` ואת `projectId` לקובץ `js/config.js`.
